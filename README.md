# One More Cup

A quiet evening scene — banked coals, a warm kettle, a train passing somewhere far off — written to slow the reader down rather than tell them to slow down. Short lines, plain words, one image that stays lit after the last line.

## Run

```bash
python3 main.py
```

Writes the entry to `/output/entry.txt`.

## Notes

- The entry is 220 Unicode code points.
- Deterministic: a fixed string, no randomness, time, or network — repeated runs are byte-identical.
